# Student Record Management System

## Overview

A simple CLI-based Student Record Management System developed using Java. This project allows users to manage student records using CRUD operations.

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Menu-driven CLI interface

## Technologies Used

- Java
- ArrayList
- OOP Concepts
- Classes and Objects
- Encapsulation

## Project Structure

### Student.java
Contains the Student class with student details such as:
- ID
- Name
- Marks

It also contains constructors, getters, and setters.

### StudentManagementSystem.java
Contains the main program, menu, ArrayList, and CRUD operations for managing student records.

## How to Run

Compile the program:

```bash
javac Student.java StudentManagementSystem.java
java StudentManagementSystem
